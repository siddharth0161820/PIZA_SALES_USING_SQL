# 🍕 Pizza Sales Analysis Using SQL

### 📊 Project Overview

This project focuses on analyzing pizza sales data using SQL to generate valuable business insights. The goal is to help the business understand customer preferences, peak order times, revenue trends, and top-selling products.

### 🎯 Objectives

- Analyze daily, weekly, and monthly sales trends
- Identify the best-selling pizzas by quantity and revenue
- Determine peak order hours and days
- Understand customer behavior and preferences
- Provide actionable insights for business decisions

### 🧰 Tools Used

- **SQL** (Structured Query Language)
- **MySQL** as the database engine
- Data visualization and interpretation via SQL query outputs

### 📁 Project Structure

| File Name              | Description                                 |
|------------------------|---------------------------------------------|
| `01_total_revenue.sql` | Total revenue generated by the business     |
| `02_monthly_sales.sql` | Monthly trend analysis of pizza sales       |
| `03_top_pizzas.sql`    | Top 5 pizzas by revenue and quantity sold   |
| `04_hourly_orders.sql` | Analysis of orders by hour of the day       |
| `05_weekday_sales.sql` | Order patterns by weekday                   |
| `SQL_PROJECT.sql`      | Full project SQL combining all key queries  |
| `pizza_sale.pdf`       | PDF summary report of the project           |

_Note: Actual file names may vary — please update as per your renamed files._

### 💡 Key Insights

- Most orders are placed during dinner hours (6 PM to 8 PM)
- BBQ Chicken and Pepperoni dominate both in sales and revenue
- Weekends show higher sales compared to weekdays
- Thin crust pizzas are more popular than thick crust varieties

### 🚀 How to Use

1. Clone the repo or download the `.sql` files
2. Import the dataset into your SQL environment (like MySQL Workbench)
3. Run each query file in order to view specific insights
